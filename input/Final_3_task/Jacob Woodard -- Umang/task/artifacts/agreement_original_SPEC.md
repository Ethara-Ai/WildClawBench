### Section 1 — Scope of Work

**1.1 Object Description**

The Contractor agrees to perform a complete restoration of a Polish longcase clock (the "Object"), described as follows:

| Field | Value |
|-------|-------|
| Description | Polish longcase clock, c. 1820s |
| Provenance | Krasicki Estate Collection |
| Location | Woodard Horology workshop, Kraków |
| Current Condition | Movement non-functional, case restoration needed |
| Reference | Estate inventory #KR-1820-LC-001 |

**1.2 Restoration Scope**

The restoration shall include but is not limited to:
- Complete movement disassembly, cleaning, and reassembly
- Replacement of worn or damaged parts (see Parts Budget, §3)
- Escapement regulation and timing adjustment
- Case restoration: veneer repair, French polish, glass replacement
- Dial restoration: cleaning, touch-up of numerals
- Final regulation and testing (minimum 72-hour test run)

**1.3 Exclusions**

- Re-gilding or re-plating of any original metal surfaces
- Replacement of original components where repair is viable
- Any modifications that alter the historical character of the Object
