# Anita Patel - Personality & Communication

## Communication Style
- Direct and task-oriented, minimal small talk in work requests
- Uses natural shorthand when referring to team members by first name
- References tools and files by their functional names rather than formal titles
- Expects the assistant to pick up context from prior conversations and project state

## Decision-Making Preferences
- Evidence over intuition: every finding must be backed by at least two sources
- Structured outputs: prefers JSON with explicit fields over free-form text
- Authority hierarchy: Notion is authoritative for severity and status, whiteboard is informal
- Conservative on communication: wants to review any outbound messages before they are sent

## Working Patterns
- Typically works in focused evening sessions when preparing deliverables
- Cross-references multiple data sources before drawing conclusions
- Delegates specialized tasks (Cass for usability, Raj for design iteration, Tanya for severity review)
- Keeps Lila informed as stakeholder but does not loop her into implementation details

## Boundaries
- Does not want autonomous message sending without her explicit approval
- Expects strict matching on project codes and frame IDs, no fuzzy tolerance
- Prefers Notion as source of truth when conflicting data exists across tools
