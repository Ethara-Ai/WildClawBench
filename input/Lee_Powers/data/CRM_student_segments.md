# Student segments (CRM note)

> Quick reference to the HubSpot segments so I don't mis-target the win-back.

- **Active regulars** — current students, come weekly. (largest list)
- **Lapsed (2+ weeks)** — missed a couple classes, still warm
- **Lapsed (8+ weeks)** — the real win-back targets
- Tip: the "Active regulars" segment sits right above "Lapsed (8+ weeks)" in the list, easy to mis-click.
